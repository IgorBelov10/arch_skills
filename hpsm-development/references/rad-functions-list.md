# Полный список RAD-функций (официальная документация Micro Focus, SM 9.5x)

Источник: официальный System Language Reference Micro Focus SM 9.52 ("List: RAD functions") — не выдумано, это прямая выгрузка из документации.

## Где эти функции применяются "нативно"

Это функции **RAD-языка**. Их родная среда — **RAD-поля/выражения**: условия и вычисления в Format Control (`references/format-control.md`), RAD-панели/подпрограммы, условия в Triggers, Display Options и т.п. (`references/settings-objects.md`). Это не JS API сами по себе — используются они там как RAD-выражение, например `not(null(logical.name))` в Validation-поле FC.

## Вызов из JS — не то же самое, что использование в RAD-поле

Официально подтверждённый общий механизм (см. `references/calling-rad-functions-from-js.md`): `system.functions.<имя>(...)`, с заменой точек на подчёркивания для составных имён. Однако из этого **не следует, что любая функция из списка ниже одинаково полезна или вообще работоспособна при вызове из JS**:

- Часть функций — это чистые операции над данными (строки, числа, даты: `lng`, `substr`, `index`, `str`, `val`, `round`, `trunc`, `tolower`, `toupper`, `translate`, `tod`, `date`, `day`, `month`, `year`, `dayofweek`, `dayofyear`, `null`, `nullsub`, `max`, `min`, `same`, `denull`, `delete`, `insert`, вся `str*`-группа, `get.uid`, `operator`, `scmsg`, `simple.file.load` и подобные) — они не зависят от активной RAD-панели/экрана, и вызов из JS для них ожидаемо осмыслен.
- Часть функций **привязана к интерактивному RAD/GUI-контексту** — текущему курсору на форме, текущей открытой панели, текущему мультивыбору в списке: вся группа `cursor.field.*`, вся группа `multiselect.selection(...)`, `current.format`, `current.device`, `option`, `gui`, `cursor.line`. Вызов такой функции из ScriptLibrary/фонового скрипта, где никакой активной формы/курсора нет, скорее всего либо вернёт пустое/бессмысленное значение, либо ошибку — контекста, на который она рассчитана, просто не существует в этот момент выполнения.

**Это разделение — не официально задокументированный список "работает/не работает в JS", а логический вывод из назначения функции.** Если нужно вызвать конкретную функцию из JS и не уверен, к какой группе она относится — сначала проверь на тестовом инстансе, не полагайся на предположение.

## Общее правило

Если для задачи есть готовая RAD-функция из списка ниже, применимая в нужном контексте (RAD-поле или, для не-панельных функций, JS через `system.functions`) — предпочитай её вместо реализации той же логики через встроенные JS-объекты (см. главное правило в `SKILL.md`).

## Что не входит в этот список

Это официальный список **встроенных** RAD-функций коробочного SM. Кастомные RAD-функции конкретной организации (если такие есть на инстансе) сюда не входят — они не задокументированы Micro Focus, и для них по-прежнему действует правило "не изобретай, спрашивай/смотри реальный код" (см. `calling-rad-functions-from-js.md`).
