# helpers/ — ваши кастомные ScriptLibrary-функции (реальный код с инстанса)

## Что сюда класть

Реальные `.js`-файлы с содержимым ваших ScriptLibrary-функций (например, тот самый namespace `funcs.*`/аналогичные утилиты, которые обсуждались раньше, или любые другие переиспользуемые хелперы вашей организации). Один файл — одна ScriptLibrary-запись, имя файла по имени библиотеки, например:

```
helpers/funcs.js
helpers/DDCCallRAD.js
helpers/IntSMServicePortService.js
```

Как и `references/schemas/*.xml` — это не общие знания, а подтверждённый реальный код с вашего инстанса.

## Как этим пользоваться (правило для модели)

1. **Перед тем как писать вспомогательную логику с нуля** (парсинг, форматирование, валидация, работа с датами и т.п.) — проверь, нет ли уже готовой функции в `helpers/`. Если есть подходящая — используй её (`system.library.<имя_файла_без_расширения>.<функция>(...)`, см. `references/scriptlibrary-and-triggers.md`), а не пиши то же самое заново через встроенные JS-объекты.
2. **Стиль и сигнатуры функций в `helpers/` — источник истины** для этого инстанса: если функция в `helpers/` принимает параметры в определённом порядке/формате — повторяй этот же паттерн в новом коде, который её вызывает, а не придумывай сигнатуру по аналогии с чем-то общим.
3. **Не изобретай функции, которых нет в `helpers/`**, даже если кажется, что "наверняка есть что-то похожее" — если нужной функции не видно ни в `helpers/`, ни в присланном в диалоге коде, значит либо её нет, либо она не загружена сюда — спроси пользователя, прежде чем предполагать её существование или писать что-то с нуля.
4. Если в `helpers/` несколько функций выглядят частично подходящими для задачи — не выбирай молча одну по вкусу, спроси, какая именно предпочтительна, если это не очевидно из названия/контекста.

## Поддержание актуальности

Файлы в `helpers/` — это снимок кода на момент загрузки. Если реальная ScriptLibrary-функция на инстансе изменилась, а файл здесь не обновлён — это устаревший источник истины. Обновляйте файлы здесь при значимых изменениях кода на инстансе, аналогично `references/schemas/*.xml`.
